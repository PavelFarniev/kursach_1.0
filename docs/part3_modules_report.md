# 3. Результаты разработки программного продукта

В рамках практической части был разработан модуль, включающий три взаимосвязанные функции: переключение тёмной и светлой темы интерфейса, отображение персональной статистики обучения `Pulse`, а также итоговое тестирование в конце курса. Данный модуль расширяет функциональные возможности платформы подготовки к ЕГЭ и ОГЭ, повышает удобство работы пользователя и обеспечивает дополнительный контроль усвоения учебного материала.

Разрабатываемые функции относятся преимущественно к frontend-части системы, так как именно на стороне пользовательского интерфейса реализуются визуальное оформление, отображение аналитических данных, интерактивное взаимодействие с тестами и логика завершения курса.

## 3.1. Пользовательский интерфейс

Интерфейс разработанного модуля соответствует требованиям, указанным в задании на практическую часть. Система адаптирована к условиям эксплуатации, поскольку учитывает особенности использования образовательной платформы в разных средах и сценариях работы. Переключение темы позволяет пользователю выбрать наиболее комфортный режим отображения интерфейса в зависимости от освещения и продолжительности работы, а панель `Pulse` помогает быстро оценить текущее состояние подготовки. Итоговое тестирование встроено в учебный сценарий и завершает работу с курсом только после прохождения контрольного блока.

Интерфейс модуля разработан с учетом визуальных характеристик восприятия информации. Для снижения зрительного утомления реализованы светлая и тёмная темы оформления. В обеих темах обеспечиваются достаточная контрастность, читаемость заголовков, кнопок и информационных блоков, а также единый стиль карточек и элементов навигации.

## 3.2. Фронтэнд информационной системы

Фронтенд модуля реализован на языке `TypeScript` с использованием библиотеки `React 18`. Для сборки проекта используется `Vite`, для управления состоянием приложения – `Zustand`, для стилизации пользовательского интерфейса – `Tailwind CSS`, для отправки HTTP-запросов к backend – `Axios`. Взаимодействие с серверной частью построено по модели `REST API`, формат передачи данных – `JSON`.

В рамках рассматриваемого модуля реализованы следующие функции:

- переключение темы интерфейса и сохранение пользовательского выбора;
- запрос и отображение статистики `Pulse`;
- логика прохождения итогового тестирования;
- обновление прогресса курса после успешного завершения контрольного блока.

Для функции смены темы создано отдельное глобальное хранилище состояния. При запуске приложения система сначала проверяет наличие сохранённой темы в `localStorage`, а при её отсутствии использует тему операционной системы пользователя. После выбора темы изменяется корневой CSS-класс документа, и интерфейс перестраивается без перезагрузки страницы.

### 3.2.1. Требования безопасности на фронтенде

На стороне frontend безопасность модуля обеспечивается за счет использования сессионной авторизации. В рабочем режиме приложение опирается на `HttpOnly` cookie, которые устанавливаются backend и автоматически передаются браузером при выполнении запросов. Такой подход исключает прямой доступ JavaScript-кода к реальным JWT-токенам и снижает риск их компрометации через XSS-атаки.

Для рассматриваемого модуля это особенно важно, поскольку статистика `Pulse`, прогресс обучения и состояние прохождения курса относятся к персонализированным пользовательским данным. Переключение темы не содержит конфиденциальной информации и сохраняется только как пользовательская настройка интерфейса.

### 3.3.1. Валидация ввода и реакция на ошибки

Согласно требованиям к функциональным характеристикам, frontend должен обеспечивать корректный ввод данных, проверку их полноты и понятную реакцию на ошибочные действия пользователя. В рамках рассматриваемого модуля эта логика реализована в итоговом тестировании: система не позволяет завершить проверку до тех пор, пока пользователь не выберет ответы на все вопросы, а при неудовлетворительном результате выводит понятное сообщение о том, что тест не пройден, с возможностью повторной попытки без сбоя страницы.

## 3.4. Краткая инструкция по эксплуатации модуля

Работа с модулем выполняется следующим образом.

1. Пользователь открывает платформу и при необходимости выполняет вход в систему.
2. В верхней панели пользователь может переключить тему интерфейса между светлой и тёмной.
3. После авторизации на главной странице становится доступна персональная панель `Pulse`, отображающая текущую учебную статистику.
4. Для прохождения курса пользователь открывает нужный курс и переходит на страницу обучения.
5. После изучения всех учебных слайдов пользователь проходит итоговый тест.
6. При успешном прохождении теста курс получает статус завершённого, а прогресс обновляется до `100%`.

Функциональное назначение основных элементов интерфейса следующее:

- кнопка переключения темы – изменение визуального режима интерфейса;
- блок `Pulse` – отображение учебной аналитики и рекомендаций;
- кнопка `Проверить ответы` – запуск проверки итогового теста;
- кнопка `Пройти ещё раз` – повторное прохождение итогового теста;
- кнопка `Пройти заново` – повторное прохождение всего курса.
