# Ручные тесты для 3 части отчёта

В файле приведены только ручные тест-кейсы для модулей:

- переключение тёмной и светлой темы;
- отслеживание статистики `Pulse`;
- итоговое тестирование в конце курса.

## Тест 1. Переключение светлой и тёмной темы

**Цель:** проверить, что пользователь может переключать тему интерфейса и что выбранная тема применяется ко всем основным элементам страницы.

**Предусловия:** пользователь открыл главную страницу системы.

**Шаги выполнения:**

1. Открыть главную страницу платформы.
2. Найти кнопку переключения темы в верхней панели интерфейса.
3. Нажать на кнопку переключения темы.
4. Проверить изменение цветового оформления страницы.
5. Повторно нажать на кнопку и убедиться, что тема возвращается в исходное состояние.

**Ожидаемый результат:** тема интерфейса переключается между светлой и тёмной, кнопки, текст, карточки и фон перестраиваются корректно, интерфейс остаётся читаемым.

## Тест 2. Сохранение выбранной темы

**Цель:** проверить, что после обновления страницы выбранная тема сохраняется.

**Предусловия:** пользователь уже выбрал одну из тем интерфейса.

**Шаги выполнения:**

1. Переключить интерфейс в тёмную тему.
2. Обновить страницу браузера.
3. Проверить, какая тема применяется после повторной загрузки страницы.

**Ожидаемый результат:** после обновления страницы сохраняется ранее выбранная пользователем тема.

## Тест 3. Отображение панели Pulse после авторизации

**Цель:** проверить, что после входа в систему пользователю становится доступна персональная панель статистики `Pulse`.

**Предусловия:** пользователь не авторизован.

**Шаги выполнения:**

1. Открыть главную страницу системы.
2. Выполнить вход под пользовательской учётной записью.
3. Вернуться на главную страницу.
4. Проверить наличие блока `Pulse`.

**Ожидаемый результат:** после авторизации отображается персональная панель `Pulse` с показателями активности и рекомендациями.

## Тест 4. Отображение статистики Pulse

**Цель:** проверить корректность отображения основных показателей статистики `Pulse`.

**Предусловия:** пользователь авторизован и открыл главную страницу системы.

**Шаги выполнения:**

1. Найти на главной странице блок `Pulse`.
2. Проверить наличие показателей: готовность, активность, входы, серия.
3. Проверить наличие блока динамики подготовки.
4. Проверить наличие блока рекомендаций.

**Ожидаемый результат:** в панели `Pulse` отображаются все основные статистические показатели, графический блок динамики и рекомендации по обучению.

## Тест 5. Обновление статистики Pulse после учебной активности

**Цель:** проверить, что статистика `Pulse` изменяется после действий пользователя в системе.

**Предусловия:** пользователь авторизован.

**Шаги выполнения:**

1. Открыть курс.
2. Перейти на страницу обучения.
3. Пройти несколько слайдов курса.
4. Вернуться на главную страницу.
5. Сравнить показатели активности в панели `Pulse`.

**Ожидаемый результат:** после действий в курсе обновляются статистические показатели, связанные с учебной активностью.

## Тест 6. Переход к итоговому тестированию

**Цель:** проверить, что после прохождения учебных слайдов пользователь попадает на итоговый тест.

**Предусловия:** пользователь авторизован и открыл курс.

**Шаги выполнения:**

1. Перейти на страницу обучения по выбранному курсу.
2. Последовательно пролистать все учебные слайды.
3. Дойти до последнего блока курса.

**Ожидаемый результат:** на последнем этапе курса отображается экран итогового тестирования.

## Тест 7. Блокировка завершения курса до проверки ответов

**Цель:** проверить, что курс не считается завершённым до прохождения итогового тестирования.

**Предусловия:** пользователь дошёл до финального теста курса.

**Шаги выполнения:**

1. Открыть последний экран курса с итоговым тестом.
2. Не отправляя ответы, проверить текущий прогресс курса.

**Ожидаемый результат:** курс не отображается как полностью завершённый, пока тест не пройден.

## Тест 8. Неуспешное прохождение итогового теста

**Цель:** проверить реакцию системы на неправильные ответы пользователя.

**Предусловия:** пользователь находится на финальном тесте курса.

**Шаги выполнения:**

1. Выбрать заведомо неправильные варианты ответов.
2. Нажать кнопку проверки результата.
3. Проверить итоговое сообщение системы.
4. Проверить, изменился ли статус курса.

**Ожидаемый результат:** система сообщает, что тест не пройден, показывает результат и предлагает повторную попытку; курс не переходит в завершённое состояние.

## Тест 9. Повторное прохождение итогового теста

**Цель:** проверить возможность повторной попытки после неуспешного прохождения.

**Предусловия:** пользователь уже получил отрицательный результат по итоговому тесту.

**Шаги выполнения:**

1. Нажать кнопку повторного прохождения теста.
2. Убедиться, что ответы можно выбрать заново.
3. Повторно пройти тест.

**Ожидаемый результат:** тест сбрасывается, пользователь может выбрать ответы повторно и пройти тест ещё раз.

## Тест 10. Успешное прохождение итогового теста

**Цель:** проверить, что при правильных ответах курс получает статус завершённого.

**Предусловия:** пользователь находится на экране итогового тестирования.

**Шаги выполнения:**

1. Выбрать правильные ответы.
2. Нажать кнопку проверки результата.
3. Проверить итоговое сообщение.
4. Проверить прогресс курса.

**Ожидаемый результат:** система сообщает об успешном прохождении теста, прогресс курса становится равным `100%`, курс получает статус завершённого.
