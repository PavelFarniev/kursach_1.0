# Инструкция по эксплуатации

## Порядок работы с приложением
1. Откройте главную страницу и перейдите к регистрации или входу.
2. После авторизации откройте каталог курсов и выберите нужный предмет.
3. На странице курса изучите описание, статистику и начните обучение.
4. Во время обучения переключайтесь по слайдам, отслеживайте прогресс, сохраняйте заметки и задавайте вопросы AI-ассистенту.
5. В профиле просматривайте персональные данные, список курсов и меняйте пароль.
6. Если у пользователя есть права администратора, он может открыть админку и управлять пользователями и курсами.

## Функциональное назначение меню
- `Главная`: входная точка приложения с кратким описанием платформы.
- `Курсы`: каталог учебных программ с поиском, фильтрацией и переходом к обучению.
- `Профиль`: данные пользователя, список начатых курсов, смена пароля.
- `Админка`: раздел управления пользователями и учебным контентом, доступный только администраторам.
- `Выйти`: завершение текущей серверной сессии и очистка cookie-аутентификации.

## Структура пользовательских интерфейсов
- `Лендинг`: обзор платформы и переход к авторизации.
- `Вход/регистрация`: формы доступа с клиентской и серверной валидацией.
- `Каталог курсов`: фильтры, список карточек, сообщения загрузки и ошибок.
- `Карточка курса`: подробная информация, старт/продолжение обучения.
- `Экран обучения`: слайды, прогресс, заметки, AI-чат.
- `Профиль`: сведения о пользователе и состояние обучения.
- `Админка пользователей`: редактирование ролей, активности и удаления.
- `Админка курсов`: создание, обновление и удаление курсов и слайдов.

## Особенности работы AI-ассистента
- Для AI-чата пользователь сохраняет личный `GigaChat Authorization Key` в профиле курса.
- Ключ хранится на backend в зашифрованном виде и не отображается повторно.
- При проблемах с внешним AI backend возвращает понятную ошибку вместо скрытой заглушки.

## Диагностика ошибок
- Если сессия истекла, приложение переведёт пользователя на страницу входа.
- Если сохранение заметки, обновление прогресса или AI-запрос завершились ошибкой, на экране показывается текст ошибки.
- Если действия администратора запрещены или данные неверны, backend возвращает HTTP-ошибку с текстовым описанием.
