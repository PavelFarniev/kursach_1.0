# Frontend

## Стек
- React 18
- TypeScript
- Vite
- Zustand
- Axios
- Tailwind CSS

## Основные возможности
- публичные страницы входа и регистрации;
- защищённые маршруты каталога, курса, обучения и профиля;
- admin-маршруты для управления курсами и пользователями;
- AI-чат и заметки внутри курса;
- клиентская валидация форм и понятные сообщения об ошибках.

## Безопасность
- в рабочем режиме frontend опирается на `HttpOnly` cookie, выставляемые backend;
- запросы отправляются с `withCredentials=true`;
- локальное token storage сохранено только как вспомогательный слой для mock-режима.

## Запуск
```bash
cd frontend
npm install
npm run dev
```

## Тесты и сборка
```bash
npm run test:run
npm run build
```

## Что проверяют frontend-тесты
- доступность и подписи фильтров каталога;
- клиентскую валидацию формы входа;
- устойчивость AI-чата при ошибке внешнего запроса.
